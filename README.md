# 🛡️ ODIN Sign-Up Form

A desktop-focused Sign-Up page designed as part of **The Odin Project** curriculum. This project focuses on building a semantic HTML structure, mastering CSS Flexbox for split-screen layouts, and integrating custom assets.

## 🚀 Key Features

* **Split-Screen Layout:** A clean 2-column design using pure CSS Flexbox.
* **Semantic HTML:** Structured using accessible tags (`<main>`, `<aside>`) for better code quality.
* **Custom Typography:** Integration of local fonts (`@font-face`) to match the specific "Odin" aesthetic.
* **Visual Validation:** Interactive feedback on form inputs (focus states and error styling).

## 🛠️ Built With

* HTML5
* CSS3 (Flexbox, Absolute Positioning)
* Git / GitHub
